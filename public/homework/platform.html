Homework maker

Draft a fillable worksheet, preview it, then download JSON and paste the catalog entry. After you add files to the repo and deploy, students open it from their hub.

  1. Fill lesson info and sentence lines (format below).
  2. Preview → download {id}.json into public/homework/assignments/.
  3. Copy catalog entry → paste into catalog.json assignments array.
  4. npm run deploy — copy student link to Discord.
Lesson & student
Line format (Section 1 & 2)

One sentence per line:

text before {answer} text after | dictionary | conjugation

Section 2: leave { } empty for open-ended blanks. Start a line with ! for NEGATIVE items.

トイレに {行きたい} 。 | いく | たい
!彼女が {ほしくない} 。 | ほしい | ない
Section 1 — Grammar point (auto-checked)
Section 2 — Student words (sent to Discord)
